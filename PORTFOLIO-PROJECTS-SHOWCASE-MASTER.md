## 06 Technical implementation
- **Core Systems & Architecture**: **Component-Oriented Native Systems Architecture**: (1) `Core::Game` orchestrating state machines, fixed-rate game loops, and presentation letterboxing; (2) `World::LevelGenerator` using Mersenne Twister RNG (`std::mt19937`) and BFS path verification; (3) `World::Board` grid state machine managing 8 visual biomes and 17 interactive tile behaviors; (4) `Systems::WorldSystem` handling dynamic perimeter shrinkage (battle royale ring collapse) and trap escalations; (5) `Systems::AudioManager` generating mathematical sine and square waveforms directly into `SDL_AudioStream`; (6) `UI::BitmapFont` rasterizing 8x8 ASCII glyphs via bitwise run merging; (7) `Systems::SaveSystem` providing persistent cross-platform file I/O.
- **Algorithms & Data Structures**: **Breadth-First Search (BFS)** for shortest-path solvability and optimal move calculations (\(O(V + E)\)), **Mersenne Twister (`std::mt19937`)** pseudo-random number generation, **Horizontal Run-Length Bit Merging** for font rasterization, **Trigonometric Wave Synthesis** for sound generation, and **Manhattan Distance Metric** for hazard proximity calculations.
- **Key Engineering Decisions**: Selected SDL3 over SDL2/SFML to take advantage of modernized audio stream APIs (`SDL_AudioStream`), native logical presentation scaling (`SDL_SetRenderLogicalPresentation`), and updated mobile touch gesture events.
